# 🌍 World Flags Explorer

A gorgeous, beginner-friendly web application built with vanilla HTML, CSS, and JavaScript that allows users to explore flags, capitals, and regions of countries from all around the globe. 

---

## ✨ Features

- **Dynamic Region Sections:** Countries are automatically grouped and displayed in neat sections based on their world region (Africa, Americas, Asia, Europe, Oceania, etc.).
- **Real-Time Search:** Instantly search for any country by typing its name into the search bar.
- **Region Filter:** Filter countries by specific geographic regions using a clean dropdown menu.
- **Smooth UI/Hover Effects:** Modern gradient backgrounds, card lift animations, and smooth image zoom effects built with pure CSS.
- **Live Data:** Fetches up-to-date country information and flag assets dynamically from the public [REST Countries API](https://restcountries.com/).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, CSS Grid, Flexbox, and responsive layout designs.
- **JavaScript (ES6+):** Asynchronous API data fetching (`async/await`), DOM manipulation, array filtering, and dynamic rendering.

```text

🚀 How to Run the Project Locally
Clone or Download this repository/folder to your local computer.

Ensure all three files (index.html, style.css, and java.js) are in the same directory.

Double-click index.html or open it with any modern web browser (Chrome, Firefox, Edge, Safari) to view and use the app!
